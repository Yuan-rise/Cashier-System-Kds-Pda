##  📝  **项目介绍**

缘启点餐收银系统，专为餐饮行业设计的高效管理软件，集成（安卓版）收银机点餐系统、小程序扫码点餐、PDA手持点餐收银软件，KDS电子厨显系统，多端联合，完美对接助力商家、运营平台提升运营效率。

##  :tw-1f4e2:  **技术架构**

##  :tw-1f4d6: **系统功能**


### **收银机功能**

登录功能：商家输入账号、密码登录收银系统。<br/>
设备连接：点击链接小票打印机打印/连接钱箱。<br/>
点餐功能：商品展示、商品下单、清空菜单、备注、优惠、称重商品、赠送、删除。<br/>
桌台点餐：桌台加菜、取号、修改菜单、叫号、打印小票、清台、结算订单、桌台点餐、查看预约单。<br/>
取餐叫号：进行叫号操作，如果可以就餐点击可就餐进行就餐状态、可根据取餐号进行点餐。<br/>
会员管理：查看会员信息，进行充值操作、可查看充值记录。<br/>
订单管理：订单信息展示，可进行退款操作、查看详情信息、打印小票。<br/>
商品管理：商品信息展示，可进行编辑商品信息、上下架操作。<br/>
交班功能：交班信息展示，当前汇总打印、日汇总明细、交班并登出。<br/>
报表功能：订单交易统计、储蓄卡统计、访问统计，可根据不同配置进行状态、类型选择查询筛选。<br/>
打印机配置：打印机显示信息、添加打印机、测试打印机、解绑。<br/>


### **小程序点餐功能**

登录功能：用户通过微信小程序授权登录账户。<br/>
扫码点餐：可通过微信扫一扫进行店铺点餐页面。<br/>
会员注册：用户可以点击注册会员进入本店铺会员注册。<br/>
店内堂食：点击进入点餐页面，用户点餐下单后店内堂吃。<br/>
到店自提：点击进入点餐页面，用户点餐下单后商品打包，用户到店自提。<br/>
预约服务：用户未到店铺，可提前点击预约到店时间。<br/>
优惠卷：点击可查看、领取店铺优惠卷。<br/>
积分商城：点击查看积分商城消费可获取积分，兑换物品。<br/>
会员卡：可查看获取的会员卡。<br/>
联系商家：可点击直接拨打店家电话。<br/>
订单信息：所有订单信息，可根据待付款、已付款、已完成、已取消进行订单筛选。<br/>
账户余额：查看用户余额信息，可充值，查看记录。<br/>
邀请有礼：该页面显示邀请新用户使用可获得的奖金及其他奖励，用户可保存图片分享。<br/>

### **KDS电子厨显功能**

登录功能：商家输入账号、密码登录电子厨显系统。<br/>
首页展示：菜品信息展示，点击上方堂吃、打包、自提按钮，可筛选。<br/>
菜品管理：可选择菜品出菜，全部菜品出菜，清除菜品。<br/>
取餐叫号：显示有的取餐排号信息包含制作中，可取餐。<br/>
排队叫号：显示页面入餐排号信息，包含当前叫号，排号信息。<br/>
系统设置：可设置菜品预警/呼叫文本/呼叫次数。<br/>

### **PDA点餐收银功能**

登录功能：商家输入账号、密码登录PDA点餐收银系统。<br/>
点餐功能：商品展示、商品下单、加入购物车功能。<br/>
桌台点餐：桌台加菜、结算订单、桌台点餐。<br/>
临时菜品：点击可添加临时商品信息。<br/>
会员信息：点击可查看店铺的会员信息。<br/>
交接管理：当日汇总查看当时所有交易汇总数据，业绩点击打印汇总进行打印。<br/>
桌台取号：取号页面，可选择桌台、输入人数、姓名、手机号进行取号。<br/>
叫号功能：点击叫号进行呼叫，点击就餐用户可进行用餐， 点击过号，则该排号已过号。<br/>
桌台信息：查看桌台信息，使用中得状态可进行清台结账、加菜操作。
订单信息：订单信息展示，可进行退款操作、查看详情信息、打印小票。<br/>
打印机：点击可查看链接的打印机，可添加/关闭/解绑操作。<br/>
